# Prividium sandbox role inventory

This non-secret inventory is generated by `prividiumcli init`. It groups all
sandbox identities by purpose and never contains private keys.

- Sandbox domain: `sandbox.example.com`
- Ethereum settlement network: Sepolia (`11155111`)
- L2 chain ID: `1900000001`
- Role-set fingerprint: `GENERATED_SHA256`

## 1. Chain deployment and governance

The ecosystem deployer, ecosystem governor, and chain owner are funded automatically from the sandbox funding wallet.

## 2. Settlement operators

The commit, prove, and execute operators receive Sepolia ETH from the sandbox
funding wallet before protocol broadcast.

## 3. Sandbox funding

The generated report displays one customer-funded address:

> Customer action: run **`prividiumcli fund`** and send only the requested Sepolia
> ETH to the sandbox funding wallet. Do not fund the other role addresses manually.

## 4. Service and passive accounts

The fee account and dormant optional-service wallets appear here. Optional
profiles are not funded by the default sandbox workflow.
